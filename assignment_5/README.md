# Assignment 5 – JavaScript Programs

## Tasks
1. Take two numbers as input and display their sum, difference, product, and quotient.  
2. Create an array of 5 numbers and find the largest, smallest, and sort in ascending & descending order.  
3. Build a form with name, email, and age fields. Validate that name is not empty, email is valid, and age is between 18–100.  
4. Create a student object with properties. Add a new property, update grade, and display all details.  
5. Create a function using array methods to remove odd numbers, multiply the remaining by 2, and find their sum.
