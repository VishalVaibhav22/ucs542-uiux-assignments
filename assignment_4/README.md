# College Fest Website (Assignment 4 Upgrade)

This project is part of the **UCS542 UI & UX Specialist** course. It's an upgraded multi-page website for the college fest, featuring a modern, responsive design and multimedia content.

---

## Features

* **Fully Responsive Design**: The layout seamlessly adapts to mobile, tablet, and desktop screens for a great user experience on any device.
* **Advanced CSS Layouts**: Uses **Flexbox** for aligning navigation and footer content, and **CSS Grid** for a dynamic, responsive photo gallery.
* **Multimedia Integration**:
    * An embedded **video** on the home page showcases highlights from previous events.
    * An **audio** message on the schedule page greets and guides participants.
* **Enhanced Styling & Interactivity**:
    * Precise styling using a wide range of CSS selectors (ID, class, attribute, pseudo-classes, and pseudo-elements).
    * Improved spacing and structure with the CSS Box Model (`margin`, `padding`, `border`).
    * Interactive UI with `:hover` and `:focus` effects on links, buttons, and form inputs.

---

## Pages

* `index.html` – Home page with a welcome message and video highlights.
* `events.html` – List of available events.
* `schedule.html` – Detailed event schedule with an audio guide.
* `register.html` – User registration form.
* `gallery.html` – Responsive photo gallery.
* `contact.html` – Contact information and FAQs.

---

## Run

No setup is needed. Just open `index.html` in your browser to get started.
